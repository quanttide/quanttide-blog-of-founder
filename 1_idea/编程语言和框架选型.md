我们放弃了用了 10 年的 Python，然后转向了多语言的最新方案。

首先是服务端，我们一开始用 Django 转 FastAPI，后来整体放弃了 Python 转向了 Go。

一个直接的好处就是 Go 可以直接二进制上线，不需要容器化了，像部署 FasS 就非常方便。

我们在客户端选型上尽可能地避开了 JavaScript。如果实在要用的话，就用 TypeScript+React。

目前，我们这个 APP 主要使用的是 Flutter，小程序主要使用的是 Taro。官网主要使用的是 React。

尽可能避免 Python 和 JavaScript 的主要原因是，我们发现它们很容易被 AI 乱搞，在生产环境之中遭到破坏。所以，我们优先选择可以编译的语言，以及以编译的二进制包的形式发布。

另外一方面，国内容器发布的基础设施生态比较差。由于各种各样的原因，镜像站被封，各大云厂商提供的支持也比较贵和糟糕。所以相比之下，使用 FaaS 发布或者是直接上虚拟机都会更好一点。
